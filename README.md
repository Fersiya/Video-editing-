# Montage Sorter

Раскладывает хаотичную папку с материалом для монтажа по структуре проекта: видео, звуки, картинки, графика, проекты. Сначала предпросмотр, потом перемещение; последнюю сортировку можно отменить.

## Установка
Скачай `MontageSorter-Setup-x.y.z.exe` из [Releases](../../releases/latest) и запусти. Права администратора не нужны. В установщик уже встроены Python и ffmpeg. В мастере можно выбрать ИИ-режим (по процессору или по видеокарте NVIDIA): он докачает нужные модули, а модели скачаются при первом скане.

Ярлык открывает программу в браузере (`http://127.0.0.1:8765`, а если порт занят другой программой, то следующий свободный). Закрыл вкладку — сервер сам завершится.

## Что получается
```
01_Footage/<тема>             видео (тема определяется по кадру)
02_Audio/Music/<настроение>   аудио длиннее 10 с + примерный BPM
02_Audio/SFX/<категория>      аудио короче 10 с (+ переименование: whoosh_03.wav)
03_Images/<тема>              фото
04_Graphics                   PSD/AI/SVG и PNG с прозрачностью
05_Project                    .prproj / .aep / .drp ...
06_Other                      всё остальное
07_Exports                    пустая папка под рендеры
99_Duplicates                 точные копии (по хэшу)
```
Лог перемещений лежит в `.sorter_log` внутри выбранной папки, по нему работает «Отменить».

ИИ: CLIP (кадры и фото) и CLAP (звуки), оба работают локально. Теги и настроения правятся в `app/classify.py` (`TOPICS`, `SFX_TAGS`, `MOODS`).

## Разработка
```
pip install -r requirements.txt        # + torch transformers для ИИ-режима
python -m app                          # нужен ffmpeg в PATH
```

## Выпуск версии
Релиз собирается автоматически (GitHub Actions, `.github/workflows/release.yml`):
Вариант 1: на GitHub открыть Actions → «Release installer» → Run workflow, указать версию (например `1.0.0`).
Вариант 2: `git tag v1.0.1 && git push origin v1.0.1`.
В обоих случаях workflow соберёт Windows-установщик на Inno Setup и создаст релиз `v<версия>` с приложенным `.exe`.

## Что нового в 1.0.3
- **Амбиенты** (дождь, гул кафе, воздух комнаты) теперь определяются по звучанию, а не по длине: длинные уходят в `SFX/Атмосфера`, короткие музыкальные отбивки (джинглы) — в музыку.
- **Видео анализируется по трём кадрам** (20/50/80 %), чёрные кадры пропускаются.
- **Вертикальные** (9:16) и **slow-mo** (от 59 fps) видео кладутся в отдельные подпапки: `01_Footage/Вертикальные/…`, `01_Footage/Slow-mo/…` (галочка в шапке).
- **Ручная правка**: открой карточку, нажми на файл и выбери другую папку до «Применить».
- **Режим «Копировать»** рядом с кнопкой «Применить»: исходники не трогаются; «Отменить» удаляет только созданные копии (если оригинал на месте).
- Длинные пути Windows (больше 260 символов) и быстрый отсев дубликатов по размеру + началу/концу файла.

## Что нового в 1.0.4: «Нужна помощь»
- Если ИИ не уверен в картинке, видео или звуке, сверху появляется плашка «Не уверена в N файлах» с кнопкой **Разобрать**.
- Окно разбора показывает фото, проигрывает видео (до 12 с) или звук (до 60 с) и предлагает 4 лучшие догадки с процентами. Можно нажать цифру 1–4, вписать своё название или оставить как есть. Пробел — играть/пауза, → — пропустить.
- Твои ответы **запоминаются** (`%LOCALAPPDATA%\MontageSorter\memory.json`): при следующем скане похожие файлы размечаются сами и помечаются ★.
- Ползунок **«Строгость ИИ»** в шапке: правее — чаще просит помощи, левее — реже. Базовые пороги лежат в `REVIEW_BASE` (`app/server.py`), близость для памяти — в `app/memory.py`.
