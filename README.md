# Montage Sorter

Раскладывает хаотичную папку с материалом для монтажа по структуре проекта: видео, звуки, картинки, графика, проекты. Сначала предпросмотр, потом перемещение; последнюю сортировку можно отменить.

## Установка
Скачай `MontageSorter-Setup-x.y.z.exe` из [Releases](../../releases/latest) и запусти. Права администратора не нужны. В установщик уже встроены Python и ffmpeg. В мастере можно выбрать ИИ-режим (по процессору или по видеокарте NVIDIA): он докачает нужные модули, а модели скачаются при первом скане.

Ярлык открывает программу в браузере (`http://127.0.0.1:8765`). Закрыл вкладку — сервер сам завершится.

## Что получается
```
01_Footage/<тема>             видео (тема определяется по кадру)
02_Audio/Music/<настроение>   аудио длиннее 10 с + примерный BPM
02_Audio/SFX/<категория>      аудио короче 10 с (+ переименование: whoosh_03.wav)
03_Images/<тема>              фото
04_Graphics                   PSD/AI/SVG и PNG с прозрачностью
05_Project                    .prproj / .aep / .drp ...
06_Other                      всё остальное
07_Exports                    пустая папка под рендеры
99_Duplicates                 точные копии (по хэшу)
```
Лог перемещений лежит в `.sorter_log` внутри выбранной папки, по нему работает «Отменить».

ИИ: CLIP (кадры и фото) и CLAP (звуки), оба работают локально. Теги и настроения правятся в `app/classify.py` (`TOPICS`, `SFX_TAGS`, `MOODS`).

## Разработка
```
pip install -r requirements.txt        # + torch transformers для ИИ-режима
python -m app                          # нужен ffmpeg в PATH
```

## Выпуск версии
Релиз собирается автоматически (GitHub Actions, `.github/workflows/release.yml`):
```
git tag v1.0.1 && git push origin v1.0.1
```
Workflow соберёт Windows-установщик на Inno Setup и приложит его к релизу.
